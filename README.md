# Mint Report HTML

把粗略中文笔记、项目进展或业务材料整理成 Mint 风格的动态汇报 HTML；支持多人分别制作、预览、直接编辑和工作文件合并，并在最后一次性发布可编辑 PPTX 与 PDF。

## 安装

把下面的链接发给支持 GitHub Skills 的 Agent：

https://github.com/chuhanma2-coder/mint-report-html

然后告诉它：

> 帮我安装这个 GitHub 仓库中的 `mint-report-html` Skill。

安装完成后，建议新建一个任务再开始使用。

## 使用

直接把材料发给 Agent，例如：

> 请使用 Mint Report HTML，把下面的笔记整理成一份动态汇报。只使用我提供的事实，先理解内容关系再设计页面；先给我 HTML 审阅，确认后再发布正式 PDF/HTML。

不需要在 Prompt 中重复说明 `E` 编辑、16:9、无页眉页脚页码或图片离线内嵌；这些是 Skill 硬门。动画或特殊嵌入需求仍应明确说明。

默认输出包括：

- 可离线打开的单文件 HTML；
- 确认发布后生成的当前内容 PDF，以及需要时的 16:9 可编辑 PPTX；
- 内容结构、来源台账和 QA 报告。

生成的 HTML 支持滚动与左右翻页、方向键导航、按 `E` 编辑文字、表格、图表、图片和关系图，按 `H` 清屏（`Esc` 恢复），以及图片、图表和详情互动。

多人协作时，协调人先生成一次任务卡；每个人只管理一个 `.mint-section.html` 工作文件。领导可分别直接修改并保存；协调人一次合并所有当前工作 HTML，先在完整 HTML 中继续修改，再发布统一的 HTML、PPTX 和 PDF。ZIP 仅作为内嵌技术格式，正常用户流程不反复导出。个人阶段不生成 PPTX/PDF。

## 与原版有什么不同

| 对比项 | 原版 `mint-report-deck` | 新版 `mint-report-html` |
|---|---|---|
| 主要用途 | 正式汇报、固定页数、PPTX 和多格式审计 | 日常汇报、内部分享、动态 HTML 和网页演示 |
| 页面结构 | 使用受控的 16:9 版式与几何合同 | 先确定整套叙事和视觉方向，再自由设计每个场景 |
| 视觉自由度 | 强调 HTML、PDF、PPTX 结构一致 | 保留 Mint 品牌，但允许更丰富的构图、动效和互动 |
| 页面阅读 | 一页一页的传统演示结构 | 支持滚动叙事，也保留左右翻页和方向键导航 |
| 输出格式 | HTML、PDF、可编辑 PPTX | 动态可编辑工作 HTML、当前版本 PDF、最终可编辑 PPTX，以及内容与来源结构文件 |
| 适合场景 | 监管、资本、法律、正式决策材料 | 项目进展、内部分享、业务复盘、方案说明和互动展示 |

新版不是把原版换一种颜色，而是把“不能出错的内容底座”和“页面必须长什么样”拆开：Skill 负责守住事实、逻辑、来源和中文可读性，Agent 在这些边界内自由决定怎样呈现得更好看。

## 底层能力

- **原始信息锁定**：给原始内容建立稳定定位，避免摘要后关键事实静默丢失。
- **中文内容编译**：识别主体、动作、状态、数字，以及并列、递进、时间、因果、对比和层级关系。
- **整套叙事规划**：先判断每个场景要回答的管理问题，再安排阅读顺序和重点。
- **来源与事实边界**：页面结论可以回到原始内容核对；没有提供的信息不自动补写。
- **中文标题合同**：桌面标题最多两行，按语义换行，不使用拥挤的负字距，也不把长句强塞成汉字墙。
- **真实渲染 QA**：检查桌面、笔记本和手机视口中的溢出、遮挡、标题换行、导航和编辑能力。
- **独立内容核心**：仓库已包含所需的内容编译脚本，不依赖或修改本机的 `mint-report-deck`。

## 实现效果

- 桌面端使用固定 1920×1080 设计画布并等比缩放，保持演示构图稳定；手机端使用同内容的受控重排。
- 使用清亮的 Mint 方案 C：浅翡翠底、白色内容面、翡翠主色、数据蓝和珊瑚强调色。
- 页面不再默认重复卡片或固定母版，可根据内容组合图表、流程、关系图、图片、视频和说明。
- 重要结论无需点击即可看到；互动用于补充比较、聚焦和展开细节。
- 所有实际可见的正式文字都进入编辑覆盖率统计，默认可按 `E` 修改；页码、派生值等锁定内容必须声明原因。
- 按 `H` 可隐藏导航、翻页箭头和编辑控件，`Esc` 或恢复按钮重新显示；控件遮挡正文会阻断交付。
- 动效关闭或打印为 PDF 时，核心信息仍保持完整。

## 说明

这是独立 Skill，不会覆盖原来的 `mint-report-deck`。多人 HTML-first 制作后需要最终可编辑 PPTX，继续使用本 Skill；只有 PPT-only、固定页数或严格跨格式几何一致时才使用 `mint-report-deck`。

当前候选版本：`v0.12.0-rc.1`。本版把章节协作包内嵌进单一工作 HTML，增加同文件保存、修订谱系、改名无关合并、分叉阻断、编辑几何门禁、容量预检、按关系加载表达规则，以及单浏览器会话最终发布。首次和个人审阅只生成工作 HTML；PPTX/PDF 只在最终发布生成一次。
