# 数据关系与首选表达路由

先判断管理问题和数据关系，再决定表达。不得根据“数字多”机械选图表。选择顺序固定为：

```text
管理问题 → 真实关系 → 是否需要精确查数 → 数据量和标签长度 → 表达形式
```

## 单个指标与状态

| 数据关系或目的 | 首选表达 | 备选 | 禁止或慎用 |
|---|---|---|---|
| 单个核心数字 | 大数字＋单位＋口径 | 大数字＋一句结论 | 单柱图、饼图 |
| 当前状态：完成、延期、风险 | 状态标签＋关键解释 | 红黄绿状态灯 | 饼图 |
| 指标＋同比或环比 | 大数字＋变化箭头 | 小型趋势线 | 两个无关系的孤立数字 |
| 当前值＋目标值 | 子弹图、进度条 | 当前/目标并列 | 仪表盘 |
| 当前值＋上下限 | 区间图 | 数字＋阈值说明 | 普通柱状图 |
| 多个核心 KPI 总览 | KPI 摘要带＋小型趋势 | 紧凑指标组 | 每个数字单独成图 |

## 时间、趋势与计划

| 数据关系 | 首选表达 | 适用边界 |
|---|---|---|
| 单指标随时间变化 | 折线图 | 月、季、年趋势 |
| 趋势并强调累计规模 | 面积图 | 累计用户、累计收入 |
| 多个指标同一时间趋势 | 多折线图 | 通常不超过 4 条 |
| 多组趋势且量纲不同 | 小多图 | 优先于双坐标轴 |
| 实际值与目标值随时间变化 | 实线＋目标虚线 | 经营目标跟踪 |
| 计划值与实际值 | 双折线或分组柱 | 强调偏差 |
| 前后两个时点变化 | 坡度图 | 国家、产品前后变化 |
| 很多时间点但只看方向 | 迷你趋势线 | KPI 总览 |
| 周期性变化 | 日历热力图或周期折线 | 日活、周内规律 |
| 项目计划随时间推进 | 甘特图或里程碑时间轴 | 不使用经营折线图替代 |
| 名次随时间变化 | 排名变化图 | 对象数量必须可读 |

## 比较、排序与差距

| 数据关系 | 首选表达 | 适用边界 |
|---|---|---|
| 多类别大小比较 | 横向条形图 | 类别名称较长时优先 |
| 少量类别简单比较 | 柱状图 | 通常 3 至 8 类 |
| 明确排名 | 降序横向条形图 | 同时显示名次和数值 |
| 第一名与其他对象差距 | 强调色条形图 | 第一名使用主强调色 |
| 两个同口径指标比较多个对象 | 分组柱状图 | 不同口径不得强行并列 |
| 同一对象两种状态 | 哑铃图 | 目标/实际、去年/今年 |
| 多对象前后变化 | 坡度图 | 强调升降方向 |
| 与基准或均值比较 | 偏差条形图 | 以零点或基准线为中心 |
| 多指标综合比较 | 点图；少量对象可用雷达图 | 雷达图不得承载大量对象 |
| 多国家、多产品、多指标 | 比较矩阵或热力图 | 需要查全貌时优先 |

## 构成、占比与集中度

| 数据关系 | 首选表达 | 适用边界 |
|---|---|---|
| 单一总体的简单构成 | 100% 堆叠条形图 | 优先于饼图 |
| 2 至 5 项静态占比 | 环形图 | 仅在结构很简单时使用 |
| 多对象构成对比 | 100% 堆叠条形图 | 国家、渠道结构比较 |
| 构成同时看绝对规模 | 普通堆叠柱状图 | 同时保留总量和结构 |
| 多层级构成 | 矩形树图 | 业务线、产品、子产品 |
| 头部集中度 | 帕累托图 | 柱状图＋累计占比 |
| 正负构成 | 发散堆叠条形图 | 收益/损失、正负评价 |
| 层级占比 | 旭日图 | 仅在层级关系确实重要时 |

## 转化、流转与贡献

| 数据关系 | 首选表达 | 适用边界 |
|---|---|---|
| 线索、申请、审批、放款 | 漏斗图 | 每级显示数量和转化率 |
| 收入、成本、利润 | 瀑布图 | 表达增减贡献 |
| 年初值经过变化到年末值 | 瀑布图 | 预算、利润、余额变化 |
| 多来源流向多去向 | 桑基图 | 渠道流向、资金流向 |
| 单一路径业务过程 | 流程图 | 步骤、角色、结果 |
| 多分支处理过程 | 泳道图 | 强调责任人和部门 |
| 输入、处理、输出 | IPO 流程图 | 系统或业务机制 |
| 价值产生环节 | 价值链图 | 经营链路 |
| 阶段转化并强调流失原因 | 漏斗＋原因标注 | 不得只展示转化数字 |

## 关系、相关性、分布与地域

| 数据关系 | 首选表达 | 适用边界 |
|---|---|---|
| 两个变量是否相关 | 散点图 | 价格与销量、投入与产出 |
| 相关性＋第三个规模变量 | 气泡图 | 气泡大小表示规模 |
| 多变量相关程度 | 相关矩阵热力图 | 不适合用于精确查值 |
| 数据落在哪些区间 | 直方图 | 金额、时长等分布 |
| 多组数据分布对比 | 箱线图 | 中位数、离散度、异常值 |
| 地区位置与指标 | 分级着色地图 | 国家、省、市表现 |
| 地区点位与规模 | 气泡地图 | 网点、用户、门店 |
| 密集时间与对象表现 | 热力图 | 国家×月份、产品×周 |
| 用户留存 | 留存矩阵热力图 | Cohort 分析 |
| 聚类或分群 | 散点分群或分群矩阵 | 必须有真实分群依据 |

## 目标、进度、风险与决策

| 管理问题 | 首选表达 |
|---|---|
| 实际完成到什么程度 | 进度条或子弹图 |
| 哪些任务正常、延期、阻塞 | 状态矩阵 |
| 目标、当前值、差距和行动 | 目标差距表 |
| 风险概率与影响程度 | 风险矩阵 |
| 多方案选择 | 加权决策矩阵 |
| 两个维度划分对象 | 2×2 矩阵 |
| 多条件逐步判断 | 决策树 |
| 优先级排序 | 价值×难度矩阵 |
| 工作计划和负责人 | 行动清单或责任矩阵 |
| 战略目标落到指标 | 战略地图或目标树 |
| 指标之间的因果链 | 驱动因素树 |

## 层级、结构与系统关系

| 数据关系 | 首选表达 |
|---|---|
| 上下级组织关系 | 组织树 |
| 总目标拆分子目标 | 目标树 |
| 指标逐层拆解 | 指标树 |
| 产品、模块、功能 | 分层架构图 |
| 系统之间交互 | 系统架构图 |
| 多实体依赖关系 | 关系网络图 |
| 角色与职责关系 | RACI 矩阵 |
| 部门与流程关系 | 泳道图 |
| 底层能力支撑上层能力 | 能力分层图 |
| 多因素共同影响结果 | 驱动因素图 |
| 确实循环发生的过程 | 闭环图 |
| 单向过程 | 箭头流程，不得伪装成闭环 |

## 定性信息与证据

| 内容 | 首选表达 |
|---|---|
| 一条核心结论 | 结论标题＋2 至 3 条证据 |
| 多项问题及原因 | 问题、原因、影响结构 |
| 问题与解决方案 | 左右对照 |
| 多方案优缺点 | 比较表 |
| 用户原话或访谈 | 引语＋背景，不编造成统计结论 |
| 原始文件截图 | 截图＋高亮区域＋解释 |
| 产品界面说明 | 界面图＋编号标注 |
| 多张图片讲过程 | 图文序列 |
| 案例介绍 | 背景、做法、结果 |
| 经验总结 | 做法、效果、适用条件 |
| 信息不确定 | 待确认项，不补写 |
| 内容密集且需要精确查阅 | 表格或附录，不强行图表化 |

## 经营汇报组合样本

以下路由来自真实 Mint 16:9 经营汇报样本。它们是关系识别示例，不是固定模板；换一批材料时仍须先验证事实关系。

| 原始关系或管理问题 | 首选表达 | 必须保留 | 禁止或慎用 |
|---|---|---|---|
| 多区域分别承担执行底座、利润复制、战略期权 | 区域组合图＋角色轴 | 各区域角色、进入路径、先后关系 | 只按国家逐页罗列 |
| 多种牌照门槛及可开展业务不同 | 牌照阶梯或分层能力图 | 门槛、业务边界、风险承担者 | 把牌照类型画成无方向流程 |
| 银行、合规中介、客户形成授权与撮合关系 | 三方桥接或能力链 | 谁授权、谁获客、谁审批、谁承担风险 | 用因果箭头暗示中介承担信贷风险 |
| 审批、注资、上线有明确前置条件 | 闸门式时间轴 | 实际、目标、预测、风险窗口的状态差异 | 把预测日期画成已完成事实 |
| 股东、投资平台、本地持牌主体逐层持股 | 股权树＋权益公式 | 直接/间接比例、乘法关系、审批边界 | 仅用饼图隐藏控制层级 |
| 多对象、五维评分，但战略优先级不等于总分 | 评分矩阵＋角色排序说明 | 单项依据、战略角色、非机械排序理由 | 只给总分并自动宣布第一名 |
| 多区域跨三年依次验证、复制、放大 | 年度路线图或泳道 | 年份、区域、闸门和依赖 | 将所有动作画成互不相关的里程碑 |
| 需要管理层确认资源、核验、原则和治理动作 | 决策清单或决策矩阵 | 决策内容、Owner/条件/验证方式（来源有时） | 把建议伪装成已批准事项 |
| P0/P1 产品共同构成一期经营组合 | 优先级组合栈 | 产品角色、优先级、依赖能力 | 每个产品独立成页且不说明组合关系 |
| 风险档位决定额度、期限、定价 | 风险矩阵或决策树 | 输入条件、输出策略、边界 | 用连续趋势图伪造规律 |
| 总设备池逐级筛选到白名单和首批样本 | 漏斗＋阶段说明 | 每级数量、分母、筛选条件、转化或保留率 | 只展示最终样本而隐藏分母 |
| 80%基础盘与20%增量盘走不同触达路径 | 双路径＋占比 | 占比口径、触达来源、共同落点 | 无总量时画面积大小误导规模 |
| 多渠道分别承担信任、转化、教育、长尾覆盖，最终汇入同一入口 | 多路径汇流图 | 渠道角色、统一落点、归因方式 | 把并列渠道画成前后步骤 |
| 账户连接多种资金进入和使用出口 | 账户中枢＋资金流 | 流向、清结算主体、账户角色 | 没有流量数据时使用桑基宽度 |
| 供应商按身份、证件、人脸、征信、AML顺序调用且成本口径不同 | 过程链＋节点成本 | 步骤顺序、供应商、单笔/年度等不同口径 | 将单笔成本与年度成本直接画同轴柱状图 |
| 年初预算－余量＝滚动预测，且H1实际/H2计划组成全年 | 预算桥＋阶段分解 | 公式、实际/计划状态、总额校验 | 把H2计划写成已发生投入 |
| 多费用类别比较滚动预测、预算余量和使用率 | 排序条形图＋精确表格 | 类别、预测、预算、余量、使用率和管理动作 | 为短表格设置占满整页的固定高度 |

组合原则：一页可以同时使用“主关系＋辅助关系”。例如预算页可用预算桥回答总盘问题、分类使用率条回答结构问题、三条管理动作回答下一步；不能因为存在三种表达形式就自动拆成三页。

## 反向禁用规则

- 禁止“出现多个数字就必须画图”。
- 日期、编号、版本号、电话号码和无可比关系的数字不触发图表。
- 只有两三个数字且一句话更清楚时，使用文字或大数字。
- 用户需要精确查数时保留表格。
- 口径、单位、对象或时间周期不同的数据不得直接比较。
- 样本不足时不得绘制看似稳定的趋势或相关性。
- 关系不清楚时保留表格或列为待确认，禁止 AI 猜测。
- 双坐标轴仅在同一时间维度、关系明确且无法用小多图表达时使用。
- 饼图或环形图只用于少量、互斥且合计为整体的类别。
- 雷达图只用于少量对象和同量纲指标，不用于精确比较。
- 桑基图、闭环图、因果箭头和相关性图必须有来源支持的真实关系。
- 源材料已有关键图表时必须保留其数据、口径和关系，不得降级为文字摘要。
- 任何图表必须具备清楚的标题、可识别的对象或系列标签，以及解释数值所必需的真实单位、统计周期和对象范围。来源必须在内部来源台账中完整可追溯，但默认不得把原始文件名、任务卡路径、负责人或其他审计信息画到汇报页面；只有用户明确要求可见引用时才展示来源。

## 图表标签与配色合同

颜色首先表达数据身份和业务语义，不用于装饰。HTML、PDF、PPTX必须使用相同的系列顺序、名称、颜色和线型。

| 数据情况 | 配色与标签规则 |
|---|---|
| 单系列、多个类别 | 所有柱默认同一数据蓝 `#2F86A6`；只有材料明确要求强调的一个对象可改为橙色 `#F08A5D`，不得给每根柱随机换色 |
| 单系列、恰好两个独立对象 | 两根柱固定为蓝色 `#2F86A6`、橙色 `#F08A5D`，对象名称必须直接可见 |
| 两个系列、任意数量类别 | 第一系列固定蓝色 `#2F86A6`，第二系列固定橙色 `#F08A5D`；必须显示与数据模型完全一致的两个系列名称 |
| 三至六个系列 | 依次使用蓝 `#2F86A6`、橙 `#F08A5D`、玉绿 `#087C66`、紫 `#7A6BB7`、金 `#D6A73C`、灰 `#69766F`；图例顺序与数据顺序一致 |
| 超过六个系列 | 不继续增加相近颜色；优先筛选关键系列、使用小多图、热力图或可查阅表格，未展示系列仍须有去向 |
| 实际与目标 | 实际使用蓝色实线或实柱，目标使用橙色虚线或轮廓；图例必须写明“实际”“目标”，不得只靠颜色猜测 |
| 正负、增减、风险状态 | 只有数据本身确有正负或风险语义时使用玉绿/珊瑚红；不得把普通第二系列误画成风险色 |

柱状图和条形图：

- 每根柱必须能通过类别标签和系列图例唯一识别。分组柱状图不得只显示类别名而省略系列名。
- 两个系列在每个类别下形成两根柱时，固定蓝橙配色；系列顺序在所有页面保持一致。
- 默认显示关键值；标签过密时保留轴刻度、端点值和管理结论所依赖的值，不得删除原始数据。
- 堆叠图必须显示各分段系列名；100%堆叠图同时说明占比口径。

折线图和面积图：

- 单折线使用数据蓝实线，并在末端直接标注系列名；关键节点显示数值。
- 双折线固定蓝色实线与橙色实线，同时使用不同点形；即使黑白打印也能区分。
- 三至四条折线按多系列色板分配，并组合不同点形；优先在线尾直接标注，图例作为补充。
- 超过四条折线优先改用小多图、排名变化图或高亮一条其余置灰；不得形成无法辨认的“意大利面图”。
- 目标线、基准线、预测线必须使用虚线并明确写出名称；不得用颜色暗示来源中不存在的好坏判断。
- 可比较系列默认共享同一绝对纵轴；不得按每条系列各自最大值归一化后仍宣称比较绝对规模。
- 数值跨越零点时必须显示共同零轴；首次由负转正的期间应直接标注。
- 只有明确要求指数化时才允许把各系列基期设为 100，并在图上显示“指数（基期=100）”。
- 多系列单位不同优先拆成小多图；双轴必须明确两个单位和业务理由。

散点、气泡、热力和地图：

- 散点图的颜色只表示来源中真实存在的分组；连续数值使用单向或发散色阶，不把连续变量硬切成随机类别。
- 气泡大小必须有尺寸图例，颜色分组必须有颜色图例。
- 热力图使用单向色阶表达从低到高；只有存在真实正负中心时才使用发散色阶。
- 地图无数据区域使用中性灰，不能与最低值使用同一种颜色。

所有图表的发布门：

- 系列名称、类别名称、单位和关键数值不得只存在于编辑器或内部JSON中，必须在最终静态状态可见。
- 不得使用仅靠红绿区分的方案；颜色之外至少再提供文字、线型、点形或直接标签。
- 图例缺失、图例与数据模型不一致、两个系列使用近似颜色，均阻断发布。
