# 浏览器保存支持矩阵

| 环境 | 当前版 HTML | 直接保存 | 保证的降级路径 |
|---|---|---|---|
| Chrome / Edge 桌面版 | 支持 | 当 `showSaveFilePicker` 可用且用户授权时，点击“保存当前版”或 `Cmd/Ctrl+S` 写回所选文件 | 下载一个包含全部修改的当前版 HTML |
| Safari / Firefox 或禁用文件写入 API 的环境 | 支持预览与编辑 | 不作为正式承诺 | 下载一个包含全部修改的当前版 HTML |
| 离线 `file://` | 支持 | 本机 Chrome 152 已确认 `isSecureContext=true` 且 API 存在 | 同上 |

自动化门禁已经覆盖直接写入逻辑、取消、单 HTML 回退、保存后解包和修改回读。系统原生文件选择器及浏览器重新打开后的授权恢复受浏览器安全策略控制，不能假装永久授权；重新打开时如被要求，用户再次选择当前文件即可。

无论走哪条路径，正常用户都不需要导出 ZIP。文件可以改名，合并身份来自内嵌 manifest，不来自文件名。
